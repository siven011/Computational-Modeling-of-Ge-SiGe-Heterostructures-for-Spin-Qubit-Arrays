# Ge/SiGe Heterostructure Optimisation for Spin Qubit Arrays

> An end-to-end computational study linking epitaxial growth parameters to qubit array performance across six layers of physics.

---

## Overview

Germanium hole-spin qubits in strained Ge/SiGe quantum wells are a leading platform for scalable solid-state quantum computing. Their performance — gate fidelity, qubit-to-qubit uniformity, and manufacturing yield — is determined by two heterostructure design parameters: the substrate Ge fraction **x** and the quantum-well thickness **L**. These must be chosen before the first device is grown.

This project treats the design problem as a joint optimisation over all five physical constraints simultaneously: dislocation safety, HH–LH splitting, manufacturing yield, g-factor uniformity, and single-qubit gate fidelity. The result is a quantitative recommendation (x = 0.79, L = 8.3 nm) with an explicit identification of the binding constraint.

## Objectives

| # | Script | What it computes |
|---|--------|-----------------|
| 1 | `objective1_strain.py` | Biaxial strain tensor (ε∥, ε⊥, ε_bi) and Matthews–Blakeslee critical thickness h_c(x) |
| 2 | `objective2_birpikus.py` | HH–LH splitting ΔE(x, L) from Bir–Pikus deformation potential + finite-well FDM solver |
| 3 | `objective3_montecarlo.py` | Monte-Carlo yield analysis; tornado variance decomposition; aleatoric vs epistemic uncertainty |
| 4 | `objective4_gfactor.py` | g-factor variability σ(g∥)/g∥ and inter-qubit addressability margin |
| 5 | `objective5_gate_fidelity.py` | Lab-frame Schrödinger evolution, RWA simulation, quasi-static 1/f noise ensemble, gate fidelity |
| 6 | `objective6_optimisation.py` | Joint FoM landscape, Pareto front, recommended operating point, robustness scan |

## Key Results

| Quantity | Value |
|----------|-------|
| Recommended x* | 0.786 ± 0.005 |
| Recommended L* | 8.32 ± 0.5 nm |
| HH–LH splitting ΔE | 94.4 meV (target > 50 meV) |
| MB safety margin L/h_c | 70% (binding constraint) |
| Parallel g-factor g∥ | 13.96 |
| Larmor frequency ω_L/(2π) at 0.5 T | 97.7 GHz |
| Manufacturing yield P(ΔE > 50 meV) | ≈ 100% |
| g-factor spread σ_g/g | 1.88% |
| Single-qubit gate fidelity F | 99.96% |
| Compound fidelity over 100 qubits | 96.1% |

The optimum sits exactly on the dislocation-safety boundary — identifying **epitaxial growth control** as the binding constraint, not yield or gate fidelity.

## Physics methods

- **Strain**: Vegard's law + cubic elasticity; free-surface boundary condition σ_zz = 0 [6, 7]
- **Band structure**: Bir–Pikus deformation potential for biaxial strain in the J = 3/2 manifold [8]; Luttinger–Kohn k·p framework [2]
- **Quantum confinement**: Finite-difference discretisation of the 1D Schrödinger equation; sparse Lanczos eigenvalue solver (`scipy.sparse.linalg.eigsh`)
- **Statistics**: Gaussian linearisation for the yield map; 50,000-sample vectorised Monte Carlo for validation; tornado variance decomposition [10]
- **Dynamics**: Adaptive RK45 integration of the Schrödinger equation (`scipy.integrate.solve_ivp`); quasi-static 1/f charge-noise ensemble; density-matrix averaging
- **Optimisation**: Exhaustive grid search over 30,800 design points; Pareto-front extraction
